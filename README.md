# Graphite

Overlay MMR pour **Rocket League** : une petite pilule discrète par-dessus le jeu avec ton MMR, ton bilan de session et
tes victoires / défaites, mis à jour quelques secondes après chaque game. Une appli de réglages complète permet de
choisir les infos affichées, leur position et tout le style (thèmes, couleurs, polices, disposition).

## Télécharger

➡️ **[Graphite-Setup.exe](https://github.com/clocloRA35132125/graphite/releases/latest/download/Graphite-Setup.exe)** (Windows 10/11)

Graphite se met ensuite à jour tout seul.

## Premier lancement

L'appli te guide en 4 étapes : Rocket League détecté, résultats en direct activés (l'API de stats officielle du jeu,
désactivée par défaut — un clic suffit, puis relance le jeu), compte détecté, MMR récupéré.

Conseil : mets Rocket League en **plein écran fenêtré** (Réglages vidéo du jeu) pour être sûr de voir l'overlay.

Graphite n'injecte rien dans le jeu et ne lit pas sa mémoire : il est compatible avec l'anti-triche.
